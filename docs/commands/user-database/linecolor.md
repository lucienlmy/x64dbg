# linecolor

Set the background color of a line in the disassembly view. When called with a single argument (`linecolor red`) the color is applied to the current disassembly selection.

## arguments

`arg1` Address of the line to color. When only one argument is given, this is the color instead.

`arg2` Color preset: `red`, `green`, `blue`, `yellow`, `orange`, `purple`. The actual colors can be customized in the Appearance dialog.

## result

This command does not set any result variables.
