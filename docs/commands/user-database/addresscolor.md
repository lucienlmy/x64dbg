# addresscolor

Set the background color of an address. When called with a single argument (`addresscolor 1`) the color is applied to the current selection.

## arguments

`arg1` Address to color. When only one argument is given, this is the color instead.

`arg2` Color preset: a number from `1` to the configured color count (`AddressColorCount`, default `6`). The actual colors can be customized in the Appearance dialog (`Address Color 1` .. `Address Color N`).

## result

This command does not set any result variables.
