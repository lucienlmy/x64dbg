# addresscolor

Set the background color of an address. When called with a single argument (`addresscolor red`) the color is applied to the current selection.

## arguments

`arg1` Address to color. When only one argument is given, this is the color instead.

`arg2` Color preset: `red`, `green`, `blue`, `yellow`, `orange`, `purple`. The actual colors can be customized in the Appearance dialog.

## result

This command does not set any result variables.
